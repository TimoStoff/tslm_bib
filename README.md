# Aionic paper guides

Shared resources for preparing scientific papers and figures.

- [`bib/`](bib/) contains the shared TSLM BibTeX library and its maintenance tools.
- [`style_guide/`](style_guide/) contains guidance for designing scientific figures.

Each subfolder has its own agent instructions. Read the nearest instruction file before making
changes.
